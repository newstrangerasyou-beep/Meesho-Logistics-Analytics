# 📦 Meesho E-Commerce Logistics & Profit Leakage Optimizer

## 📌 Project Overview
This project targets **Return to Origin (RTO)** rates and operational inefficiencies within a low-cost, high-volume e-commerce marketplace framework inspired by Meesho. By analyzing logistics pipelines in PostgreSQL, the project isolates product return anomalies, tracks regional fulfillment rates, and uncovers margin degradation caused by sunk return shipping fees.

## 🛠️ Tech Stack & Skills Used
* **Data Architecture:** SQL / PostgreSQL (CTEs, Window Functions, and Case Logic)
* **Business Intelligence:** Power BI Desktop (Data Modeling & Custom Background UI Layouts)
* **Analytical Calculations:** Advanced DAX (Time Intelligence, Filter Context Overrides)

## 📊 Key Operational Insights
* **Fulfillment Velocity:** Tracked average transit windows (averaging **16.78 days**) to pin down carrier partner delays.
* **Logistics Bottlenecks Uncovered:** Identified that a small cluster of product categories accounted for a disproportionate **20%+ RTO rate**, dragging down net profit margins.
